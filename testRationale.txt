This sections tests the functionality of the LOGIN and LOGOUT function implemented
in part 2 of phase0.

Now we test a point of failure; using the LOGIN command while still in session. This
should FAIL regardless of wether the login contains the UID of the current session or of
a different session because only one session can exist at a time both on the server and
on the client. Both should fail and the request and response uid should be that of the user
in session.

>> {"uid":"fbs", "op":"LOGIN"}
